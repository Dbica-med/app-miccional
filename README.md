# Acompanhamento miccional — app dos pais

Aplicativo (PWA) do calendário do xixi e diários miccionais. Sem dados pessoais: apenas código da criança e registros.

- `src/` — código-fonte; `python3 build.py` gera `index.html` e `sw.js`.
- `src/config.js` — endereço do programa do Google (`API_URL`).
